# Metric Risk — public pages

Three pages plus a dated report archive, published as static HTML by the engine
that produces them. Nothing here is written by hand.

| Page | What it is |
|---|---|
| [`index.html`](index.html) | Report archive, newest first |
| [`calibration.html`](calibration.html) | **The scored track record** — how often the engine's declared risk boundary was actually breached |
| [`disclaimer.html`](disclaimer.html) | Educational content only. No trade instructions are issued anywhere in the output |

## Why the calibration page is the one that matters

Every published reading is later scored against realised price.

**EUR/USD — the 95% risk boundary was breached 264 times in 4,972 scored readings: 5.3% against a declared 5%.** Gold runs 5.6%. Both pass Kupiec and Christoffersen, the two tests a risk desk would apply.

Pattern detection is table stakes in this sector; every provider ships it. Publishing your own error rate is not — and it is the only claim on this site a reader can check rather than believe.

## What this repository is not

It is the published output, not the engine. The engine is a .NET 10 codebase — 481 files, 1,149 passing tests — and is not open source.
